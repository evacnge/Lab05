Spatial Filtering

Lab Summary

This lab focuses on spatial filtering in image processing. It covers different filtering techniques, including Box Filter, Gaussian Filter, Median Filter, Bilateral Filter, and Laplacian Sharpening. These filters are used for smoothing images, reducing noise, preserving edges, and enhancing image details.

The lab demonstrates how different filters and kernel sizes affect the quality and appearance of images.
